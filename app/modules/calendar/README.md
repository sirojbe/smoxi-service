# Calendar

Uchrashuvlar, smenalar, eslatmalar va ish buyurtmasiga bogʻlangan tadbirlar.

## Ochiq API

- `CalendarService` — CRUD, reschedule, soft-delete, oraligʻ boʻyicha roʻyxat
- `CalendarPage` — Oy / Hafta / Kun / Kun tartibi

## Qoidalar

- Soft-delete
- `ends_at` > `starts_at`, timezone-aware UTC
- Sidebar: `calendar` (Reports dan keyin)
