# Mijozlar moduli

Mijozlar va ularning qurilmalarini boshqarish.

## Maqsad

- Mijoz yaratish, tahrirlash, yumshoq oʻchirish
- Qurilma roʻyxati (telefon, noutbuk, va hokazo)
- Telefon boʻyicha dublikat nazorati
- IMEI / seriya noyobligi

## Ochiq API

- `CustomerService`
- `CustomersPage`
