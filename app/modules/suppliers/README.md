# Yetkazib beruvchilar va xarid

Yetkazib beruvchilar kartochkasi, xarid buyurtmalari va omborga qabul qilish.

## Ochiq API

- `SupplierService`
- `SuppliersPage`

## Qoidalar

- Soft-delete yetkazib beruvchilar uchun
- Qabul qilinganda ombor zaxirasi `IN` harakati bilan oshadi
- Qabul qilingan buyurtmani bekor qilib boʻlmaydi
- Manfiy zaxira taqiqlangan (ombor qoidalari)
