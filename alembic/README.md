# Alembic migrations (SMOXI Service)

Lightweight Alembic scaffold. **Do not treat this as a full cutover yet.**

## Coexistence with `schema_patches`

While the app still runs on SQLite desktop installs, `app/database/schema_patches.py`
continues to apply incremental ALTER/ADD patches on startup. Alembic revisions
and schema patches may run in parallel during the transition period:

1. Prefer **schema_patches** for small SQLite-safe upgrades until a proper
   baseline revision exists.
2. Use Alembic for PostgreSQL / multi-environment schema management going forward.

## Next step

Generate the first autogenerated revision after models are stable:

```bash
alembic revision --autogenerate -m "baseline"
```

Review the generated SQL carefully before applying — do **not** dump a huge
hand-written initial migration without review.

```bash
alembic upgrade head
```

## Configuration

- `alembic.ini` — `sqlalchemy.url` is a placeholder; `alembic/env.py` overrides
  it from `get_database_settings().url`.
- Metadata: `Base.metadata` from `app.models.base`.
